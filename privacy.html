LoveSync Privacy Policy

Last updated: 20 November 2026

What the app accesses

LoveSync uses Google Sign-In and the Google Drive API only to create and use one private "LoveSync" folder in the user's Google Drive, which is shared with the one partner the user invites. Notes, drawings and snaps are saved in that folder.

What we collect

Nothing. The developer runs no servers and does not receive, store, sell or share any user data. Email addresses are not stored on the phone; the shared folder only keeps one-way hashes to match partners.

Calls

Voice and video calls are peer-to-peer and encrypted (WebRTC). A public signalling relay only passes connection setup messages; call audio/video is not recorded.

Google user data

LoveSync's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data is never used for advertising or transferred to third parties.

Deleting data

Users can delete the LoveSync folder from their Google Drive at any time and remove access at myaccount.google.com/permissions.
